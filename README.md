# Interstellar Bare Server (Singapore Optimized)

High-performance Bare server for Interstellar, tuned for:
- Singapore region hosting (Railway)
- Low latency for Japan users
- YouTube streaming support
- Ultraviolet / Interstellar compatibility

## Deploy to Railway
1. Push this repo to GitHub.
2. Create a new Railway project → Deploy from GitHub.
3. Set region to **Singapore (ap-southeast-1)**.
4. Add environment variable:
   - PORT = 3000
5. Deploy.
